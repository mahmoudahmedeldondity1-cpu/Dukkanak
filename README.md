# دُكَّانَكْ — Dukkanak

متجر إلكتروني حقيقي (Full-Stack) بُني بـ Next.js + PostgreSQL + Prisma + NextAuth.

## ✅ الجزء الجاهز حاليًا (المشروع الكامل — المراحل 1 إلى 4)

**المتجر (Storefront):**
- الصفحة الرئيسية، كل المنتجات، فلاتر وترتيب، صفحات التصنيفات
- صفحة منتج كاملة (صور، متغيرات، تقييمات + فورم تقييم حقيقي)
- بحث فوري (Autocomplete) + صفحة نتائج + حالة "لا نتائج" ذكية
- سلة حقيقية + Checkout كامل (محافظات مصر، Validation، دفع عند الاستلام)
- إنشاء طلبات حقيقية بخصم المخزون تلقائيًا ومنع تجاوز الكمية المتاحة
- صفحة تأكيد الطلب + "طلباتي" + تفاصيل كل طلب + المفضلة
- صفحة العروض، "وصل حديثًا"، صفحة 404، وكل الصفحات القانونية والمعلوماتية
- تسجيل دخول/حساب حقيقي بكلمة مرور مشفّرة

**لوحة تحكم الأدمن:**
- نظرة عامة بإحصائيات حقيقية (إيرادات، مخزون منخفض...)
- إدارة المنتجات: إضافة، نشر/إلغاء نشر، حذف، **استيراد/تصدير CSV**
- إدارة الطلبات: تغيير الحالة فعليًا + **تصدير CSV**
- **سجل العمليات (Audit Log)**: كل عملية حساسة (إنشاء/تعديل/حذف منتج، تغيير حالة طلب...) مسجّلة
- **إعدادات المتجر**: اسم المتجر، رقم التواصل، حد الشحن المجاني، **وضع الصيانة** (فعّال بالكامل ويُخفي المتجر عن الزوار مع بقاء وصول الأدمن)
- التقييمات: API الموافقة/الإخفاء جاهز (التقييم الجديد لا يظهر للعامة قبل موافقة الأدمن)

**الأمان:**
- كل صفحات ومسارات API الخاصة بالأدمن محمية بفحص الجلسة والصلاحية (Role-Based Access Control)
- تشفير كلمات المرور (bcrypt)، Validation من طرف السيرفر لكل نموذج (Zod)
- Rate Limiting أساسي على تسجيل حساب جديد وتسجيل الدخول (حماية من محاولات التخمين المتكررة)
- Security Headers (X-Frame-Options, X-Content-Type-Options, إلخ)
- لا تُخزَّن بيانات بطاقات بنكية، ولا توجد أي مفاتيح API وهمية في الكود

**الدفع:** بنية Payment Gateway جاهزة — الدفع عند الاستلام مفعّل بالكامل، والبطاقة/المحفظة جاهزة للربط الفعلي مع Paymob (راجع `lib/payment/gateway.ts`)

## 🧪 قائمة اختبار (QA Checklist) — نفّذها بنفسك بعد التشغيل

استخدم بيانات الأدمن التجريبية (admin@dukkanak.com / Admin@123) وأنشئ حساب عميل عادي جديد لاختبار:

- [ ] تسجيل حساب جديد / دخول / خروج / محاولة دخول ببيانات خاطئة
- [ ] البحث بالاسم، بالـ SKU، وبكلمة غير موجودة (تأكد من ظهور اقتراحات بديلة)
- [ ] فلترة المنتجات بالسعر، والترتيب بكل الخيارات
- [ ] فتح منتج، تغيير الكمية، محاولة تجاوز المخزون المتاح
- [ ] إضافة للسلة، تعديل الكمية، حذف منتج، تطبيق كوبون WELCOME10
- [ ] إتمام Checkout ببيانات ناقصة (تأكد من ظهور رسائل الخطأ) ثم بيانات كاملة
- [ ] التأكد إن المخزون قلّ فعليًا في لوحة الأدمن بعد إتمام الطلب
- [ ] إضافة تقييم لمنتج، والتأكد إنه ما يظهرش للعامة قبل الموافقة من الأدمن
- [ ] الدخول كأدمن: تغيير حالة الطلب، نشر/إلغاء نشر منتج، حذف منتج
- [ ] تصدير المنتجات والطلبات CSV والتأكد من فتحهم صح في Excel
- [ ] استيراد CSV منتجات وتأكد من ظهورهم كمسودات
- [ ] تفعيل وضع الصيانة من الإعدادات، والتأكد إن الزوار العاديين بيشوفوا صفحة الصيانة بينما الأدمن لسه شايف الموقع
- [ ] محاولة الدخول لصفحة `/admin` بحساب عميل عادي (يجب أن تُرفض)
- [ ] اختبار الموقع على شاشة موبايل (320px–414px) وتابلت وديسكتوب

## كيف تشغّل المشروع محليًا (على جهازك)

### 1. المتطلبات
- Node.js (نسخة 18 أو أحدث) — نزّله من https://nodejs.org
- محرر أكواد زي VS Code (اختياري لكن مريح)

### 2. تثبيت الحزم
افتح Terminal جوه مجلد المشروع واكتب:
```
npm install
```

### 3. قاعدة البيانات (مجانية)
1. سجّل في https://supabase.com
2. أنشئ مشروع جديد (New Project)
3. من Settings → Database، انسخ الـ Connection String (URI)
4. انسخ ملف `.env.example` وسمّيه `.env`، وحط فيه رابط قاعدة البيانات:
```
DATABASE_URL="الرابط اللي نسخته من Supabase"
NEXTAUTH_SECRET="أي نص عشوائي طويل"
NEXTAUTH_URL="http://localhost:3000"
```

### 4. إنشاء الجداول وتعبئة البيانات التجريبية
```
npm run db:push
npm run db:seed
```

### 5. تشغيل المشروع
```
npm run dev
```
افتح المتصفح على: http://localhost:3000

بيانات دخول الأدمن التجريبية:
- الإيميل: admin@dukkanak.com
- كلمة المرور: Admin@123

## كيف تنشر الموقع على الإنترنت (مجانًا)

1. سجّل في https://vercel.com (بحساب GitHub أفضل)
2. ارفع مجلد المشروع على GitHub (أو استخدم زرار "Deploy" المباشر في Vercel)
3. من Vercel، اختر "Import Project" واختر الريبو
4. في خانة Environment Variables، ضيف نفس المتغيرات اللي في `.env`
5. اضغط Deploy — هتاخد رابط شغال زي `dukkanak.vercel.app`

## ملاحظات أمان مهمة
- لا تشارك ملف `.env` مع حد أبدًا — فيه مفاتيح حساسة
- غيّر `NEXTAUTH_SECRET` و كلمة مرور الأدمن التجريبية قبل النشر الفعلي
- بوابة الدفع (Paymob) لسه مش متربطة — هنضيفها في مرحلة لاحقة
